# The Fool's Reef

Карточная игра на Python и Pygame.

## Запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& ".\.venv\Scripts\python.exe" main.py
```

Рабочий каталог при запуске должен быть корнем репозитория.
